# OS-aware backup with automatic discovery

Branch `feat/os-aware-discovery` (from main `9282b42`, v1.5.9). Backup finds what is installed or configured but not declared, classifies each item by the systems it works on, and restore only applies what fits the receiving system. Engram memories travel too.

## Specs

S1. User: "crei qeu ya soportabamos auto todos los files obvi hay cosas que son solo para mac otras sirven para linux pero adaptadas o windows adaptadas se entidne??" and "si dale siq uiero todo obvio como dije se que ejemplo enm mi mac tengo una app llamada smart window esa es de sweift con bbbrew obvio solo sirve para mac eso es loq ue me refiero que sepa que apps po que no siirve apra caada sistemas donde se restaure ese bacckup se entiende?"
S2. Manifest OS model. An app may declare `os: [darwin, linux, windows]` (subset); a path mapping may declare `os:` (subset) and `src_os:` (per-OS source override, e.g. `{linux: ~/.config/x, windows: ~/AppData/Roaming/x}`). Absent `os` keeps today's behavior (applies everywhere). Restore skips an app or path whose `os` excludes the receiving system and reports it as "not for <system>" without failing; a path with a `src_os` entry for the receiving system deploys to that source. Status and backup ignore apps/paths not for the current system. Older manifests without these fields load unchanged.
S3. Package discovery. Full `dots backup` (CLI and TUI) lists Homebrew formulae installed on request, casks and taps that no manifest app or staged Brewfile declares, and adds each to the staged manifest (never the repository) as an app with an install recipe and an `os` list: casks -> `[darwin]` (e.g. `smartwindow`, `godot-mono`); formulae whose bottles or requirements are macOS-only -> `[darwin]`; formulae with Linux bottles -> `[darwin, linux]`; unknown -> `[darwin]`. Output prints one "New:" list naming each item and its systems.
S4. Config discovery. Full `dots backup` lists `~/.config/<dir>` entries no manifest path covers, stages them as config-only apps in the staged manifest with `os: [darwin, linux]`, honoring the existing secret masking and size/exclusion rules. Directories known to hold credentials or caches (at least `gcloud`, `configstore`, `github-copilot`, `gh-copilot`) are listed as skipped with the reason, not copied.
S5. Engram memories. Full `dots backup` exports Engram memories (`engram export --all`) into the stage when `engram` is installed; restore with config imports them with `engram import`. Importing the same export twice must not duplicate memories (verify; if engram duplicates, restore must skip an already-imported export). Missing engram: reported, not a failure.
S6. Help text, README and docs describe S2-S5.
